# 🚀 Java Beginner Bootcamp: 7-Day Hands-On Guide

Welcome to the **Java Beginner Bootcamp**! This repository is designed from the ground up for aspiring developers, computer science students, and anyone starting their journey with Java.

Every single line of code in this repository includes clear explanations, practical real-world scenarios, visual ASCII memory maps, and step-by-step challenges so you can learn with zero prior confusion.

---

## 🛠️ Prerequisites & Setup

To compile and run any code in this repository:

1. **Java Development Kit (JDK 17 or higher recommended)**:
   Verify your installation by running in your terminal:
   ```bash
   javac -version
   java -version
   ```
2. **Git**:
   ```bash
   git --version
   ```

---

## ⚡ Quick Start: How to Run Any Example

Each day's folder is self-contained. Navigate into any day's directory and compile the `.java` files using `javac`:

```bash
# Example: Running Day 1 code
cd day01-methods/src
javac BasicsOfMethods.java
java BasicsOfMethods
```

---

## 🌟 Philosophy of this Guide

1. **No Magic**: Every keyword (`public`, `static`, `void`, `extends`, `@Override`, etc.) is explained in plain English.
2. **Mental Models**: Learn how Java allocates memory on the **Stack** and **Heap**.
3. **Hands-On First**: Short, concise, working programs that you can copy, tweak, and run right away.
